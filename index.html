Scientific Methods & References

BioKit algorithms are based on peer-reviewed scientific methods.

  • Accurate Tm (Melting Temperature): Calculated using the Nearest-Neighbor thermodynamic model with SantaLucia enthalpy/entropy values and Owczarzy salt corrections.
    SantaLucia, J. Jr. (1998) "A unified view of polymer, dumbbell, and oligonucleotide DNA nearest-neighbor thermodynamics." PNAS 95, 1460-1465.
  • Protein Hydrophobicity (GRAVY): Calculated using the Kyte-Doolittle scale via sliding window averaging.
    Kyte, J., & Doolittle, R. F. (1982) "A simple method for displaying the hydropathic character of a protein." J Mol Biol, 157(1), 105-132.
  • Codon Translation: Utilizes the Standard NCBI Genetic Code (Transl_table 1).
  • Molecular Weight: Calculated using average elemental isotopic residue masses (minus H2O condensation per peptide/phosphodiester bond).
